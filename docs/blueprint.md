# **App Name**: RozgarMatrix

## Core Features:

- Job Listing & Search: Browse and search for jobs based on various criteria like title, location, salary range, and company. Includes robust filtering options.
- Job Posting for Employers: Employers can easily create and publish new job listings, providing detailed descriptions, requirements, and company information.
- Job Details Page: View comprehensive details for each job, including responsibilities, qualifications, benefits, and company overview, with prominent application buttons.
- User Authentication & Profiles: Secure user registration, login, and personalized profiles for job seekers (managing applications, saved jobs) and employers (managing listings, applications).
- Job Application Process: Streamlined process for job seekers to apply directly through the platform, including resume upload and cover letter submission.
- AI Job Match Tool: Leverages AI to recommend highly relevant job listings to job seekers based on their profile, skills, experience, and application history.
- AI Application Enhancement Tool: An AI-powered tool that provides intelligent suggestions for optimizing job applications, such as improving resume summaries or drafting targeted cover letter content.

## Style Guidelines:

- Primary color: A confident and professional blue (#447EC9), providing clear contrast on lighter backgrounds and signaling trustworthiness for a SaaS platform.
- Background color: A subtly desaturated, light bluish-gray (#ECEFF3), ensuring a clean, modern, and breathable interface without distractions, fostering professionalism.
- Accent color: A distinguished, modern purple (#522EDB), used sparingly for call-to-action elements, interactive components, and to draw attention to key information, adding a sophisticated visual pop.
- Body and headline font: 'Inter' (grotesque-style sans-serif) for its modern, clean, and objective aesthetic, ensuring high readability and a professional appearance across all screen sizes and text densities.
- A consistent set of minimalist icons with soft, rounded edges to complement the overall modern SaaS aesthetic. Icons should use outlines or subtle fills to maintain visual lightness.
- A desktop-first responsive design featuring a centered container with a maximum width and generous horizontal margins. Desktop layouts utilize a grid-based, multi-column structure (2-3 columns), transforming into a single, vertically stacked column for mobile devices, prioritizing clear information hierarchy.
- Interactive elements, particularly buttons, are large and touch-friendly on mobile, located strategically for thumb-friendly access (e.g., bottom navigation or sticky action buttons). Consistent padding and margins are applied throughout to ensure adequate white space and prevent overcrowding, contributing to a 'breathable' UI.
- Subtle, lightweight animations focused on providing feedback and enhancing user flow without impeding performance. Emphasis on smooth transitions and fast loading times to ensure an intuitive and seamless user experience across devices.
